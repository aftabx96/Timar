# Timar frontend

React + Vite + Tailwind v4 front end for Timar. Animations use `motion` (Framer Motion).

```bash
npm install
npm run dev
```

## What is here

| Route | Page |
| --- | --- |
| `/` | Public home page |
| `/signup` | Sign up, then a 6 digit email code |
| `/login` | Sign in with an email code or a password |
| `/setup` | Profile setup after the first sign in (role, details, photo, review) |
| `/dashboard` | Dashboard for the signed in role: adopter, volunteer, company or admin. Admin has a working Content screen |
| `/journal` | Past drives and awareness articles, read from the API |
| `/journal/drives/:id` | One drive: record and photo gallery |
| `/journal/:slug` | One article |

## Auth

`src/lib/auth.jsx` talks to the API in `../backend` (start it with `npm run dev --prefix backend`).
Vite proxies `/api` to `http://localhost:4000`. The session is an httpOnly cookie set by the server.
Until a mail server is configured, codes show up in the **Dev inbox** box at the bottom right.

## Design rules

Colours, fonts and spacing are tokens in `src/index.css`. Display type is Young Serif, body is
Schibsted Grotesk, data is JetBrains Mono. No purple gradients, no glass cards, no icon libraries:
the few glyphs are drawn in `DashboardShell.jsx`. Charts are hand drawn SVG in `components/charts.jsx`.

## Field photos

All photos are from the Timar field visit to Rehri Goth on 3 October 2026 (team Drive folder
"rehri goth feild"). `public/field/` holds 800 and 1600 px WebP copies with every bit of camera
metadata removed, including location. `src/lib/fieldPhotos.js` lists each one with its camera file
number, capture time, alt text and crop focus. Close-up portraits of local people and children were
left out on purpose; add them only with the person's consent.

## Sites map

`src/components/SitesMap.jsx` uses Leaflet with Sentinel-2 cloudless imagery from EOX
(s2maps.eu, CC BY-NC-SA 4.0: free for this non-commercial project, credit shown on the map).
A commercial launch would need a different imagery licence. Sites and their coordinates live in
`src/lib/sites.js`: Kaderu Island (Saltwater Marina's current planting site) plus Rehri Goth,
Bundal Island, Sandspit and Keti Bandar. Plot IDs in the sample data use KD- for Kaderu,
RG- for Rehri Goth, BD- for Bundal and KB- for Keti Bandar.

## Drawn island map

The map beside "How it works" (`src/components/CreekMap.jsx`) is drawn from real OpenStreetMap
coastline and mangrove data for Rehri Goth, Kaderu Island and Buddo Island. The shapes live in
`src/lib/coastShapes.js`, generated by `scripts/build-coast.cjs` (instructions at the top of that file).
Plot boundaries and survival figures will be added with the plot registry later.

## Drive record

The "With Timar" view shows the 3 October 2026 drive from `FIELD_DRIVE` in `src/lib/fieldPhotos.js`.
Date and times come from the camera; route, group size and sapling count are Saltwater Marina's
standard drive until the real numbers are filled in (then set `confirmed: true` to drop the note).
